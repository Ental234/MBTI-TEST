모든 HTML 파일을 점검한다.

점검 항목:
1. 각 페이지의 `<title>` — 비어 있거나 중복되거나 페이지 내용과 안 맞는 경우
2. 깨진 링크 — `<a href>`, `<img src>`, `<link href>`, `<script src>` 중 존재하지 않는 파일이나 잘못된 경로를 가리키는 것 (내부 링크 우선, 외부 링크는 형식만 확인)
3. 콘솔 에러 — 각 페이지를 브라우저로 열어 JavaScript 에러 / 404 리소스 에러 확인

보고 형식:
- 파일별로 통과 여부와 발견된 문제, 수정한 내용을 표로 정리한다.

| 파일 | 제목 | 링크 | 콘솔 | 상태 | 수정 내용 |
|------|------|------|------|------|-----------|

- 문제가 있으면 수정하고, 표의 "수정 내용" 칸에 무엇을 고쳤는지 적는다.
- 모두 통과하면 상태 칸에 통과로 표시한다.
